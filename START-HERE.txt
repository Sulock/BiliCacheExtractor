BiliCacheExtractor 1.4.0 - Windows x64

简体中文
解压整个程序包，双击 BiliCacheExtractor.exe 即可使用。
内置 FFmpeg 8.1.3（NVENC API 12.2）和 FFprobe，无需额外安装。
点击“FFmpeg 设置”可切换内置、本地或下载的版本，检测后点击“使用所选版本”。
NVIDIA 接口最低驱动 551.76，实际编码器以检测结果为准；无损提取不需要视频编码器。
详细说明：README.zh-CN.md、tools\README.md。

繁體中文
解壓縮整個套件，按兩下 BiliCacheExtractor.exe 即可使用。
內建 FFmpeg 8.1.3（NVENC API 12.2）與 FFprobe，不需要額外安裝。
點選「FFmpeg 設定」切換內建、本機或下載的版本，偵測後點選「使用所選版本」。
NVIDIA 介面最低驅動 551.76，實際編碼器以偵測結果為準。
詳細說明：README.zh-TW.md、tools\README.md。

English
Extract the entire package and start BiliCacheExtractor.exe.
FFmpeg 8.1.3 (NVENC API 12.2) and FFprobe are included; no installation is required.
Open FFmpeg tools to select the bundled version, local tools or a verified download.
NVIDIA API minimum driver: 551.76. Encoder availability is tested at runtime.
See README.md and tools\README.md.
