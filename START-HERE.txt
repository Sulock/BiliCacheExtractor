BiliCacheExtractor 1.3.0 - Windows x64

简体中文
1. 将整个程序包解压到可写目录。
2. 首次使用时双击 Install-FFmpeg.cmd，联网下载并校验固定版本的 FFmpeg。
3. 完成后双击 BiliCacheExtractor.exe，选择缓存目录并扫描、提取。
已手动配置兼容 FFmpeg/FFprobe 的用户可以跳过第 2 步。
FFmpeg 的许可证和来源记录保存在 tools\ffmpeg\LICENSE.txt 与 SOURCE-INFO.txt。
本软件许可证为 GPL-3.0-only，正文见 LICENSE；对应源码 ZIP 已包含在本程序包中。
详细用法见 README.zh-CN.md。

English
1. Extract the entire package to a writable folder.
2. Run Install-FFmpeg.cmd once with an internet connection to download and verify the pinned FFmpeg build.
3. Start BiliCacheExtractor.exe, select your cache folder, then scan and extract.
Skip step 2 if you already supplied compatible FFmpeg and FFprobe manually.
The FFmpeg license and origin are retained in tools\ffmpeg\LICENSE.txt and SOURCE-INFO.txt.
BiliCacheExtractor is GPL-3.0-only; see LICENSE. Its corresponding source ZIP is included in this package.
See README.md for detailed instructions.

Tested on Windows 11 23H2 x64 with .NET Framework 4.8.1.
Hardware encoding requires a compatible GPU and driver. Automatic mode can use CPU encoding.
Source and releases: https://github.com/Sulock/BiliCacheExtractor
